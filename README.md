# Kulör & interiör

Färdig statisk webbplats för GitHub Pages. Ingen installation eller byggning behövs.

## Publicera

1. Lägg `index.html`, hela mappen `assets` och `.nojekyll` i GitHub-repots rot.
2. Aktivera GitHub Pages för grenen som innehåller filerna och välj rotmappen `/`.

Behåll mappnamnen och filnamnen. Alla sökvägar är relativa, så sidan fungerar även under ett projektnamn på GitHub Pages.

## Innehåll

- `index.html`: hela sidans innehåll, utseende och funktioner.
- `assets/images/`: fem projektbilder och logotyp med transparent bakgrund.
- `assets/fonts/`: Manrope i tre vikter och tillhörande OFL-licens.

Bilder, logotyp och typsnitt ligger lokalt. Google-kartan kräver internetanslutning. Kontaktknappar öppnar besökarens mejl- eller telefonapp.

Projektbilderna kommer från kulorochinterior.se och ingår för företagets webbplats.
